## 检测程序状态判定流程（建议）

```
截屏 → 模板匹配求福(主锚点)
  ├─ 命中(≥0.85)
  │    ├─ cast_zone 出现"点击水面开始钓鱼"亮字  → READY  → 在 SAFE_CAST 随机取点点击（随机延迟）
  │    ├─ btn_left 处出现蓝/橙金按钮色块        → CATCH  → 在 name_band 分色
  │    │                                            ├─ 紫/黄 → 暂停+通知，等待人工
  │    │                                            └─ 白/绿/蓝 → 点 btn_left
  │    └─ 其余                                     → WAITING → 不做任何操作
  └─ 未命中（连续2~3帧）→ 非钓鱼界面 → 立即自动暂停 + 通知
```

辅助锚点（装备栏）可用于在求福被轻微遮挡时做二次确认，但**不可单独**作为
"在钓鱼界面"的依据（它可被隐藏）。
