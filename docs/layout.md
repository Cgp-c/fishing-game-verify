## 交互与误触区域

| 区域 | x0 | y0 | x1 | y1 | 说明 |
|---|---|---|---|---|---|
| `cast_zone` 抛竿有效区 | 20.0% | 66.0% | 82.0% | 93.0% | 真实截图黄框：下 1/3 的中间 2/3 |
| `order_panel` 订单面板 | 64.0% | 43.0% | 100% | 58.0% | 右侧中部（真实位置，**位于抛竿区上方，不重叠**）：竖排"今日订单"标题+2~3条订单+"订单详情"链接 |
| `order_rows` 订单条目 | 71.5% | 44.3% | 96.5% | 55.0% | 点击任一条目弹出订单详情 |
| `SAFE_CAST` 安全点击区 | 25.0% | 78.0% | 75.0% | 92.0% | **给检测程序的建议抛竿点击区**：抛竿区中部偏下，远离订单面板 |

**误触场景**（真实布局下订单面板与抛竿区不重叠）：若检测程序的点击**越界偏高**
（超出抛竿区上缘 y<66%）落到订单面板，会弹出订单详情——求福被遮挡 → 非钓鱼界面
→ 触发自动暂停。demo 模式以 12% 概率模拟此类误触。

## 检测程序状态判定流程（建议）

```
截屏 → 模板匹配求福(主锚点，圆心不透明小图)
  ├─ 命中(≥0.85)
  │    ├─ cast_hint 区出现"点击水面开始钓鱼"亮字 → READY → 在 SAFE_CAST 随机取点+随机延迟点击
  │    ├─ banner_strip 金色横幅 + btn_left 色块    → CATCH → 在 name_band 分色
  │    │                                            ├─ 紫/黄 → 暂停+通知，等待人工
  │    │                                            └─ 白/绿/蓝 → 点 btn_left
  │    └─ 其余                                      → WAITING → 不做任何操作
  └─ 未命中（连续2~3帧）→ 非钓鱼界面 → 立即自动暂停 + 通知
```

辅助锚点（装备面板 y15%~44%）可用于二次确认，但**不可单独**作为"在钓鱼界面"
的依据（它可被隐藏）。
