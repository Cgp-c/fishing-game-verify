# 简单钓鱼游戏验证（fishing-game-verify）

一个用于**自动化图像识别测试**的本地钓鱼小游戏。它复刻了某类手机钓鱼玩法的界面状态与视觉特征（稀有度名字颜色、求福图标锚点、顶部装备栏、每日订单面板、出售/提交订单按钮等），作为后续"纯外部图像识别 + 模拟点击"自动钓鱼插件的**本地验证测试台**。

> 本项目所有素材均为程序化生成（`tools/gen_assets.py`），不含任何商业游戏截图或资源；本项目与任何商业游戏无关，仅供学习与自动化测试研究。

## 运行

```bash
python game/main.py
```

- 依赖：Python 3.10+，仅标准库 + Pillow（`pip install pillow`）
- 窗口：540×1170（9:19.5 手机比例），标题「简单钓鱼游戏验证」（供测试程序按标题查找窗口）

### 命令行参数（验收/测试用）

| 参数 | 说明 |
|---|---|
| `--demo` | 自动演示模式：自动抛竿、自动处理鱼获，可用于长时间跑图测试 |
| `--force-rarity=白\|绿\|蓝\|紫\|黄` | 按给定顺序循环强制出鱼（快速检查五种颜色） |
| `--force-order` | 强制每次鱼获都匹配订单（快速验证「提交订单」按钮） |
| `--wait-min=3 --wait-max=6` | 自定义等待时长（秒），默认 6~15 |
| `--ad-rate=0.008` | 钓鱼期间随机插入活动公告的每秒概率（≈2分钟一次；0=禁用） |
| `--force-popup` | 进入钓鱼后立即弹一次活动公告（手动验证任意阶段弹窗） |
| `--seed=123` | 固定随机种子，便于复现 |

## 状态机（六态）

```
HOME ──进入钓鱼──> READY(准备钓鱼) ──点水面──> WAITING(钓鱼等待)
                     ^                        │ 随机6~15s
                     │                        v
              （卖鱼后小概率）          CATCH(鱼获结算)
                     │                        │
              RANDOM_POPUP(活动公告) <────────┘
                     ^
任意钓鱼态 ──随机插入（每秒0.8%）──┘   ※ 关闭后原样恢复被打断的阶段
任意钓鱼态 ──误触订单条目──> ORDER_DETAIL(订单详情，覆盖求福图标)
```

| 状态 | 求福图标 | 顶部装备/属性面板 | 订单面板 | 说明 |
|---|---|---|---|---|
| HOME | ✗ | ✗ | ✗ | 非钓鱼界面（测自动暂停） |
| READY | ✓ | ✓ | ✓ | 仅抛竿区（x20%~82%, y66%~93%）点击有效；点击订单面板（越界偏高）弹订单详情 |
| WAITING | ✓ | ✓ | ✓ | 任何点击无响应；竿尖(49%,59%)垂线至鱼漂(49.5%,84%) |
| CATCH | ✓(压暗) | ✓(压暗) | 压暗 | 全屏压暗遮罩+悬浮元素：金横幅(y20%~29%)+鱼图+名字条带+左对齐信息行+双按钮 |
| ORDER_DETAIL | ✗(遮挡) | ✓ | 高亮 | 误触订单后弹出，非钓鱼界面（测自动暂停） |
| RANDOM_POPUP | ✗(遮挡) | ✓ | 遮挡 | 随机干扰弹窗（测自动暂停）；**任意钓鱼阶段均可插入**，关闭后原样恢复被打断的阶段（等待计时暂停、鱼获保留） |

## 布局与真实游戏对齐

所有区域坐标按真实游戏截图（929×2000）像素测量校准（详见 `docs/layout.md`）：
左侧圆形图标列（垂钓助手/求福/奇异生物，y59.5%~86%）、顶部资源栏+装备/属性大面板
（y12%~44%，可隐藏）、右侧中部订单面板（x64%~100%, y43%~58%）、抛竿区黄框
（x20%~82%, y66%~93%）、结算全屏压暗遮罩+金色横幅+名字条带（左右金色纹样，
中央为稀有度颜色文字）+左对齐信息行+双按钮（y79%~86%）。

## 双锚点设计（给检测程序）

- **主锚点**：左侧「求福」圆形图标——出现与否判断是否在钓鱼界面（详见 `docs/layout.md`）
- **辅助锚点**：顶部装备/属性面板（鱼饵/鱼竿/鱼线/鱼钩+属性栏）——游戏内"设"按钮可将其隐藏，模拟真实游戏可隐藏的情形，检测程序不能依赖它
- **背景**：每次抛竿在 3 套配色（桃林/青山/芦苇）间随机切换，检测程序不能依赖背景

## 稀有度颜色（详见 docs/colors.md）

| 稀有度 | 颜色 | 鱼种示例 | 出现概率 | 检测程序应…… |
|---|---|---|---|---|
| 白 | (240,240,240) | 海星、沙丁鱼 | 40% | 自动出售 |
| 绿 | 见 colors.md | 海马、石斑鱼 | 25% | 自动出售 |
| 蓝 | 见 colors.md | 胭脂鱼、香鱼、小丑鱼等 | 20% | 自动出售 |
| 紫 | 见 colors.md | 神仙鱼、鬼头刀、月光水母 | 10% | **暂停等待人工** |
| 黄 | 见 colors.md | 霓虹鱼、鳟鱼、骨舌鱼 | 5% | **暂停等待人工** |

结算按钮：钓到的鱼匹配未完成订单 → 左下「提交订单」（橙金）；否则「出售」（蓝）。右下恒为「放入瑶池」（金）。

## 每日订单与误触检验

- 右侧中部订单面板（x64%~100%, y43%~58%，真实位置）：竖排"今日订单"标题 + 2~3 条订单（指定鱼 ×1~3），提交对应鱼获推进任务条，全部完成奖励金币并刷新
- 订单面板位于抛竿区**上方**（与真实游戏一致，不重叠）：若检测程序的点击**越界偏高**（超出抛竿区上缘）落到订单面板，会弹出「订单详情」（求福图标被遮挡）——用于检验检测程序能否正确进入"非钓鱼界面→自动暂停"链路；demo 模式以 12% 概率模拟此类误触
- `docs/layout.md` 给出了远离订单面板的「安全点击子区域」（SAFE_CAST）建议

## 项目结构

```
game/     游戏本体（tkinter + Pillow）
tools/    素材生成与色值提取脚本
docs/     颜色规格与布局坐标表
tests/    冒烟测试（截屏 + 图像识别断言）与闭环自检（多轮压力 + 模拟插件检测闭环）
```

## 测试

```bash
python tests/smoke_test.py        # 冒烟：44 项截屏+识别断言（会短暂弹出游戏窗口）
python tests/closed_loop_test.py  # 闭环自检：Part A 无 UI 压力（30 种子×240s 虚拟时间，
                                  #   ~1.7 万次钓鱼循环，随机弹窗打断/模糊点击/金币精确校验等不变量）
                                  #   Part B 模拟插件「截屏→识别→决策→点击」6 轮闭环，
                                  #   弹窗在 READY/WAITING/CATCH 轮流注入，逐帧核对识别与真实状态一致
```

闭环自检曾发现并已修复：等待期点击「设」按钮会穿透切换装备面板（违反"等待期任何点击无效"规格），
已加回归断言。
